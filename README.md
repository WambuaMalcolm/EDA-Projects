# Exploratory Data Analysis Projects

A collection of exploratory data-analysis exercises focused on understanding datasets, identifying patterns, and visualizing relationships.

## Project

- `Car Features and MSRP/` — analysis of vehicle features and pricing

## Getting Started

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install pandas numpy matplotlib seaborn jupyter
```

Open the project notebook or scripts and run the analysis interactively:

```bash
jupyter notebook
```
